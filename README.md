# DevBox

Free, open-source developer tools that run entirely in your browser.

## Tools

- **JSON Formatter** - Format, validate, and minify JSON
- **Base64 Converter** - Encode and decode Base64 strings
- **Regex Tester** - Test regex patterns with live matching
- **JWT Decoder** - Decode and inspect JSON Web Tokens
- **UUID Generator** - Generate v4 UUIDs instantly
- **Timestamp Converter** - Convert Unix timestamps to dates

## Why DevBox?

- **100% Free** - No account required, no hidden fees
- **Privacy First** - All processing happens in your browser. No data leaves your device.
- **Open Source** - Built with transparency. Contributions welcome.
- **Fast** - No server roundtrips. Instant results.

## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS

## Local Development

```bash
npm install
npm run dev
```
